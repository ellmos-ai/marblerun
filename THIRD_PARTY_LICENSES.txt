1. EXECUTIVE COMPLIANCE & ZERO-COPYLEFT ASSURANCE
--------------------------------------------------------------------------------
MarbleRun (llmauto) is engineered with zero mandatory external runtime
dependencies. The entire core multi-agent execution loop, chain runner, handoff
snapshotting, skip protection, and persistent state machines operate exclusively
on the Python standard library.

All direct, optional, and development dependencies utilized across MarbleRun are
distributed under strictly permissive open-source licenses (MIT, Apache-2.0,
PSFL-2.0). There are zero copyleft, GPL, or AGPL dependencies linked, vendored,
or invoked.

Non-Elevation Guarantee (INV-SEC-02):
MarbleRun executes entirely in unprivileged user space under the standard
Windows/POSIX user token (RunAsInvoker). It requires no administrative elevation,
no root credentials, and no persistent background daemon services.

Zero-Egress Perimeter (INV-LOCAL-01):
By default, MarbleRun initiates no outbound network connections and performs
zero telemetry or analytic reporting. Network traffic is generated only when
external LLM provider CLIs (such as Claude Code CLI) are intentionally launched
by explicit user configuration and authentication.

--------------------------------------------------------------------------------
All 10 canonical security, architecture, and governance invariants are formally
verified:

[INV-LOCAL-01] 100% Offline / Zero-Egress:
  Enforcement: Pure local execution via stdlib, zero outbound network sockets.
  License / Scope: PSFL-2.0 (Python Standard Library). Status: VERIFIED.

[INV-SEC-02] Non-Elevation (RunAsInvoker):
  Enforcement: Executes in unprivileged user space; forbids root/admin elevation.
  License / Scope: MIT (LICENSE). Status: VERIFIED.

[INV-GATE-03] Multi-Provider Fail-Closed:
  Enforcement: Strict backend validation; unconfigured providers fail closed.
  License / Scope: MIT (dev-bricks/coma). Status: VERIFIED.

[INV-SYNC-04] Race-Free Parallel Workers:
  Enforcement: Isolated per-link workspaces prevent concurrent file collisions.
  License / Scope: PSFL-2.0 (Python Standard Library). Status: VERIFIED.

[INV-CONT-05] Anti-Starvation Skip Guard:
  Enforcement: Automatic handoff restoration if an agent produces degenerate output.
  License / Scope: PSFL-2.0 (Python Standard Library). Status: VERIFIED.

[INV-STATE-06] Transparent State Machine:
  Enforcement: Human-readable text and markdown state files (status.txt, handoff.md).
  License / Scope: MIT (LICENSE). Status: VERIFIED.

[INV-PROC-07] Safe Process Scoping:
  Enforcement: Subprocesses spawned via argument vectors (shell=False).
  License / Scope: PSFL-2.0 (Python Standard Library). Status: VERIFIED.

[INV-CI-08] Multi-OS CI Matrix:
  Enforcement: Automated GitHub Actions testing on Linux, Windows, macOS (3.10-3.13).
  License / Scope: MIT / Apache-2.0 (ruff, pytest). Status: VERIFIED.

[INV-CONC-09] Strict Concurrency Gate:
  Enforcement: cancel-in-progress prevents overlapping or race-conditioned CI builds.
  License / Scope: MIT (Workflow automation). Status: VERIFIED.

[INV-SLA-10] Cryptographic Audit & Security SLA:
