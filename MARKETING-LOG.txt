================================================================================
2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. Autonomous AI Agent Engineers & Platform Architects
   - Needs: Multi-hour unattended agent runs, sequential worker-reviewer-controller pipelines, deterministic state handoffs.
   - Pain Points: Fragile cloud wrappers, in-memory context loss on process termination, runaway token costs without hard stop conditions.
   - MarbleRun Solution: Process-isolated CLI execution, transparent filesystem checkpoints (`handoff.md`, `status.txt`), hard round limits, and configurable deadline gates.

2. Multi-Agent Swarm & Handoff Developers
   - Needs: Clean separation of duties (Worker executes -> Reviewer verifies/tests -> Controller routes/stops).
   - Pain Points: Agents overwriting upstream context with empty responses or unparseable JSON blobs.
   - MarbleRun Solution: Anti-overwrite Skip-Guard (INV-CONT-05), isolated parallel worker workspaces, and single-source handoff commits.

3. Enterprise Tooling, Safety & Governance Compliance Officers
   - Needs: Strict zero-egress, auditability, permissive licensing, unprivileged execution.
   - Pain Points: Telemetry leaks, GPL license viral contamination, mandatory root/admin privileges.
   - MarbleRun Solution: 100% Offline / Zero-Egress (INV-LOCAL-01), unprivileged RunAsInvoker operation (INV-SEC-02), 100% permissive third-party dependency stack (PSFL-2.0, MIT, Apache-2.0 audited in THIRD_PARTY_LICENSES.md), dual security response SLAs (48h acknowledgment, 5 business days triage).

4. Open-Source AI Tool Builders & Local-First Developers
   - Needs: Lightweight, zero-dependency Python tool that works out-of-the-box on Linux, Windows, and macOS.
   - Pain Points: Massive dependency trees (hundreds of pip/npm packages) that break on minor version updates.
   - MarbleRun Solution: Pure Python standard library core engine with optional pluggable provider bridge (`coma`).

4. COMPETITIVE DIFFERENTIATION MATRIX
================================================================================
| Dimension | MarbleRun (llmauto) | LangGraph / CrewAI / AutoGen | Naive Shell Scripts |
|---|---|---|---|
| **Runtime Dependencies** | Zero (100% Python Standard Library) | Heavy (pydantic, langchain, cloud SDKs) | Variable (curl, jq, bash dependencies) |
| **Execution Isolation** | Native subprocess boundaries (`shell=False`) | In-process Python threads / memory | Shell subshells (vulnerable to injection) |
| **State Transparency** | Plaintext files (`status.txt`, `handoff.md`) | Proprietary graph checkpoints / DBs | Custom stdout dumps / fragile logs |
| **Context Protection** | Automated anti-overwrite Skip-Guard | Silent state overwrite on empty response | Overwrites target file blindly |
| **Multi-Provider** | Claude default, pluggable COMA (Codex/Agy) | Vendor-tied or complex config | Manual script rewriting per provider |
| **Security & Privacy** | 100% Offline / Zero-Egress, RunAsInvoker | Cloud telemetry / external API by default | Depends on curl/wget calls |
| **Licensing** | 100% Permissive (MIT / PSFL-2.0 audited) | Often complex / dual-licensed dependencies | Unlicensed / ad-hoc |

5. GOVERNANCE & RUNTIME INVARIANTS (INV-LOCAL-01 TO INV-SLA-10)
================================================================================
- INV-LOCAL-01: 100% Offline / Zero-Egress (local subprocess orchestration, zero network egress)
- INV-SEC-02: Non-Elevation & User Mode (unprivileged execution without root/admin permissions)
- INV-GATE-03: Multi-Provider Fail-Closed (unconfigured backends fail closed without insecure fallbacks)
- INV-SYNC-04: Race-Free Parallel Workers (per-worker isolated handoff workspaces)
- INV-CONT-05: Skip-Overwrite Guard (baseline snapshot restoration on truncated or skipped outputs)
- INV-STATE-06: Persistent State Machine (transparent filesystem artifacts: status, round, handoff)
- INV-PROC-07: Safe Process Scoping & Shell-Free Execution (direct argv arrays, shell=False)
- INV-CI-08: Multi-OS CI Matrix (cross-platform testing on Ubuntu, Windows, and macOS)
- INV-CONC-09: Strict Concurrency Gate (cancel-in-progress: true avoiding stale CI compute waste)
